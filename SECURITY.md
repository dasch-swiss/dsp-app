# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in DSP-APP or in the `@dasch-swiss/dsp-js` package published from this repository, report it privately by emailing **security@dasch.swiss**. Do not open a public GitHub issue for a suspected vulnerability.

Include as much detail as you can: the affected version or commit, the URL or page where it occurs, reproduction steps, and the potential impact.

## Response Expectations

We acknowledge a report within a few business days and keep you informed while we investigate and fix it.

## Supported Versions

DSP-APP is released with [release-please](https://github.com/googleapis/release-please) and deployed by DaSCH; only the latest release receives security fixes. For `@dasch-swiss/dsp-js`, only the latest published version is supported. Check that the issue reproduces on the latest release before reporting it.
